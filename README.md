# ゆきころバトル

雪玉を転がして育て、アイテムで妨害し合う2〜6人用のブラウザゲーム。

**遊ぶ:** https://kakkun15.github.io/yukikoro-battle/

## 遊び方

1. 雪玉を転がして育てる（新しい雪の上ほどよく育つ）
2. 雪の中から掘り当てたアイテムで、ほかの人をじゃまする
3. 先に雪だるまを完成させた人の勝ち

| モード | 勝ち方 |
| --- | --- |
| 雪原モード | その場で雪玉を育てて、先に100%にした人の勝ち |
| 坂道モード | 下で育てて頂上の旗まで運ぶ。届けた大きさの合計が100%で勝ち。手を離した雪玉は坂を転がり落ちる |

### チーム戦

ロビーで「チーム戦」を「あり」にすると、赤と青の2対2か3対3になる（どちらのモードでも遊べる）。

- チームの合計が「人数×100%」（2対2なら200%、3対3なら300%）になったら勝ち
- 味方は自分と同じ扱い。味方のパンチ・アイテム・転がる雪玉は当たらない
- 手ぶらで味方の雪玉のそばにいると、いっしょに押して速く進める
- スポットライトは相手の人数分の光が出る。使った側のチームは雷に打たれないが、光に先に入って相手が入れないようにじゃまできる

### よけ方のヒント

ヘビのおもちゃやつららにねらわれると、頭の上に「手」のマークが出る（スマホでは手ボタンが光る）。そのとき手のボタンを押すと、ヘビはパンチで壊せて、つららは雪玉から手を離せば気絶しない。

## 操作

| 動作 | キーボード | マウス | スマホ |
| --- | --- | --- | --- |
| 移動 | 矢印 / WASD | — | 左のスティック |
| 手（離す・パンチ） | X / F | 左クリック | 手ボタン |
| 道具（押して狙う・離して使う） | Space / E / Enter | 右クリック | 道具ボタン |

キーは画面右上の「設定」で変えられる。

## マルチプレイ

1. 1人が「マルチプレイ」→「部屋を作る」を押す
2. 出てきた4文字のコードを、一緒に遊ぶ友だちに伝える
3. 友だちは同じページを開き、「マルチプレイ」でコードを入れて「部屋に入る」

ホストのブラウザがゲームを動かすので、サーバーを借りる必要はない。接続の仲介には PeerJS の無料サーバーを使っている。

## 音楽について

### 音の作り方

BGMと効果音に音声ファイル（MP3・WAV・MIDIなど）は使っていない。ページの中のプログラムが、ファミコンと同じ4種類の音（矩形波2つ・三角波・ノイズ）をブラウザの機能（Web Audio）でその場で合成して鳴らしている。

### 曲を作って公開するまでの流れ

1. AI（Anthropic の Claude）が、著作権の切れた原曲の旋律を思い出して、音符をプログラムに直接書いた
2. 伴奏・ベース・ドラムは、Claude がその場で新しく書いた
3. 作者（kakkun15）が確認して公開した

既存のMIDIファイル・楽譜・録音は、どれも写していない。

「怒りの日」だけは、楽曲分析サイト [Hooktheory](https://www.hooktheory.com/theorytab/view/giuseppe-verdi/requiem---dies-irae) で調・テンポ・和音の名前を確認した。旋律はそのサイトに載っていないので写していない。楽譜サイト（IMSLP）も見ようとしたが、ロボット確認で止まって中身は見ていない。そのため原曲に忠実ではない編曲になっている。

### 安全だと判断した根拠

- 日本の著作権の保護期間は、原則として作者の死後70年まで（2018年12月30日施行の改正）。上の3曲の作者はいずれも1901年以前に亡くなっていて、期間を大きく過ぎている。
- 改正の時点ですでに切れていた権利は、さかのぼって延長されない（文化庁の説明）。
- MIDIデータや出版された編曲には、打ち込んだ人や編曲者の権利が別に付くことがある。このゲームはそれらを写していないので、その権利は関係しない。
- 日本語の歌詞（訳詞）には訳した人の権利が残っている場合があるが、このゲームは歌詞を使っていない。曲名を表示しているだけ。

### 気をつけている点

- Claude が旋律を何から覚えたかは確かめられない。ただし旋律そのものの権利が切れているので、覚えた経路によって権利が復活することはない。
- 伴奏は基本的な和音（主に3つのコード）だけで組んでいて、特定の編曲には似せていない。
- 以前入っていた「おめでとうクリスマス（We Wish You a Merry Christmas）」は、よく知られた形が1935年の編曲（アーサー・ウォレル）に由来し、国によって権利の扱いがはっきりしないため、オリジナル曲「雪合戦マーチ」に差し替えた。
- ルロイ・アンダーソンの「そりすべり（Sleigh Ride）」は1948年の作品で、作者が1975年に亡くなっているため権利が残っている。使っていない。
- ここに書いたのは作者側の判断で、法律の専門家の確認を受けたものではない。問題に気づいた人は Issues で知らせてほしい。
